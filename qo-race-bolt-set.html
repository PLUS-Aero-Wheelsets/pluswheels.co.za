When Do You Need the Bolt Set?

NOT using a QO RACE Aero Spider?

If you are mounting chainrings directly onto the QO RACE crankset without a spider, you need this bolt set. It provides the 4 bolts and 4 nuts required to secure BCD 110x4 chainrings to the crank arms.

Already bought the QO RACE Aero Spider?

The Aero Spider already includes this bolt set. You do not need to purchase it separately.
